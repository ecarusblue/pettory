펫토리 설치하기

홈 화면에 추가하면 앱처럼 바로 열리고, 친구가 부를 때 알림을 받을 수 있어요.

이미 설치되어 있어요. 홈 화면의 펫토리 아이콘으로 열어 주세요.

지금은 다른 앱 안의 브라우저예요. 여기서는 설치할 수 없으니, 오른쪽 위 메뉴에서 다른 브라우저로 열기를 누르거나 아래에서 주소를 복사해 Safari에 붙여 넣어 주세요.

휴대폰에서 이 주소를 열면 설치할 수 있어요.

아이폰·아이패드 내 기기
  1. Safari로 이 페이지를 엽니다. 다른 브라우저에서는 홈 화면에 추가할 수 없어요.
  2. 화면 아래쪽의 공유 버튼 을 누릅니다.
  3. 목록을 내려 홈 화면에 추가를 누릅니다.
  4. 오른쪽 위 추가를 누르면 홈 화면에 펫토리 아이콘이 생겨요.

알림은 홈 화면 아이콘으로 연 다음에 켤 수 있어요. iOS 16.4 이상이 필요합니다.

안드로이드 내 기기

설치 준비 중이에요…

  1. 위의 앱 설치 버튼을 누르고, 뜨는 창에서 설치를 누릅니다.
  2. 버튼이 켜지지 않으면 Chrome 오른쪽 위 ⋮ 메뉴에서 앱 설치 또는 홈 화면에 추가를 누릅니다.
  3. 삼성 인터넷에서는 아래쪽 ≡ 메뉴의 현재 페이지 추가 → 홈 화면을 누릅니다.

설치한 뒤 앱을 열고 알림을 허용하면, 배고플 때나 아플 때 알려 드려요.
